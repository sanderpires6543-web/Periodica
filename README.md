# Tabela Periódica da Turma

Tabela periódica interativa com os vídeos dos trabalhos de cada aluno.

## Adicionar um vídeo

1. Abre `videos.js`.
2. Cola o link entre as aspas, à frente do nome do aluno:

   ```js
   "Alexandre": "https://www.youtube.com/watch?v=XXXXXXXXXXX",
   ```

3. Guarda o ficheiro. No GitHub, usa o botão de editar (lápis) e depois **Commit changes**.

São aceites links do YouTube, Google Drive, Vimeo e ficheiros `.mp4` na pasta `videos/`. No Google Drive, o vídeo tem de estar partilhado com "Qualquer pessoa com o link". No YouTube, usa "Público" ou "Não listado" e confirma que a incorporação está permitida.

## Publicar no GitHub Pages

1. Cria um repositório público no GitHub.
2. Carrega todos os ficheiros desta pasta para a raiz do repositório.
3. Vai a **Settings > Pages**.
4. Em **Source**, escolhe **Deploy from a branch**, depois `main` e `/ (root)`, e carrega em **Save**.
5. O site fica disponível em `https://O-TEU-UTILIZADOR.github.io/NOME-DO-REPOSITORIO/` ao fim de um ou dois minutos.

## Links diretos

Cada aluno e elemento tem um link próprio, por exemplo `.../#alexandre` ou `.../#Fe`.
